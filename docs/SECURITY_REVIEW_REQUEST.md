# Security review request — P5 broker/executor chain (Gate 1)

This is the package a reviewer needs. It states exactly what to review, how to
reproduce the tests, and what evidence a PASS requires. Nothing in this
repository claims a security boundary has been independently verified.

## Scope of the review

| Component | File | What must be established |
| --- | --- | --- |
| Worker identity registry | `boru/workers.py` | An identity is created only by the owner; secrets are 0600, bounded, revocable and expiring; `valid()` is constant-time and denies a revoked/expired/unknown identity |
| Authorization broker | `boru/broker.py` | Operations, resource aliases and worker scopes are bound to a grant; replay, expiry, revocation, malformed requests and a missing consent store all deny; no consent is ever generated by a model |
| Authenticated surface | `boru/broker_service.py` | Loopback-only (a non-loopback bind is refused); one request per connection; bounded size; idle timeout; a wrong secret or unknown worker denies before any authorization |
| Bounded worker | `boru/executor.py` | Only the three alias-confined read-only operations; `O_DIRECTORY|O_NOFOLLOW`; typed fields only; content, names, paths and listings are never produced |
| Disclosure gate | `boru/privacy.py`, `boru/consent.py` | L0/L1/L2 field allowlists; recipient/field/expiry binding; replay protection; persistence of revocation across restarts; fail-closed on any error |
| End-to-end pipeline | `boru/pipeline.py` | The identity handshake is on the tested path; a denial happens before anything is acquired or released |
| Rejection ledger | `boru/audit.py` | Append-only, bounded, sanitized; no payload, path, token or provider text |
| Cross-boundary tracer | `boru/boundary.py` | An outbound request without a declared classification is refused with no network call |
| Repository connectors | `boru/connectors/` | Grant repo/ref binding; no `method`/`path` overrides; no redirects; content type, body bound, response reference, token account, workflow allowlist and typed repository encoding |
| Shell/Sandbox | `boru/sandbox.py` | Decisions only; nothing executes; host-level Shell is absent from the allowlist |

## Explicitly out of scope for this review

- Host-level process authentication and OS confinement (separate gate).
- Sandbox runtime, Docker/container isolation (separate gate).
- Live provider, GitHub/GitLab or cloud behaviour (separate gates).

## How to reproduce

~~~bash
python3 scripts/check_project.py
python3 -m unittest discover -s tests      # 556 tests
python3 scripts/evidence.py               # exit 0
~~~

Every security-relevant behaviour asserted above has a named test; a finding
should cite the test that fails, or the missing test.
